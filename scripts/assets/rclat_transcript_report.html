Methods, coverage and source provenance

Words are normalised using the archived RCLAT English scoring rule: uppercase; retain A–Z, apostrophes and spaces; collapse whitespace. Alignments use minimum word edit distance. Ties resolve to substitution, then deletion, then insertion; other valid aligners can distribute S/D/I differently while preserving total errors.

Comparisons use exact utterance IDs. Different experiments can use different populations and protocols; this report is descriptive, not a new matched superiority experiment. Device replicas are represented once. Prefix rows are hidden by default. Source records and references are read from the files listed below; no reference text is invented.
